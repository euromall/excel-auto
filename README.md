# ExcelAuto

주문·적하 엑셀 반복작업 자동화. 인보이스 프로그램(InvoiceAuto, `invoice_2610`)과 **별도로** 만들어 테스트한 뒤 합칠 예정.

## 현재 기능 (v0.4)

| 기능 | 대체하는 작업 | 상태 |
|---|---|---|
| ① 망고 → Base 추가분 (`ExcelAuto.exe`) | 2~3단계: 망고변환 파일(망고→중간→최종) 규칙 적용 + 한글 단어 변환, **Base 추가분 파일**(A~S) 생성. Base.xlsx는 읽기만 | 11-24 실제 7건·망고변환 90건과 결과 일치 |
| ② 적하 작성 (`ExcelAuto.exe`) | 6~8단계: 샵마인 수령인 정보 → 적하, 품명 조회(주문재고변환 `변환` 시트), 품명·수량 입력, Shipping 파일 만들기 | 2026-11-24 실제 파일로 결과 일치 확인 |
| 출고 체크 매크로 v2 (`vba/ShipScan.bas`) | 14단계: 선택한 행 안에서 송장 스캔 → 행 전체 연두색 + AI열 출고일 | 엑셀 실행 검증 전 |

## ① 망고 → Base 추가분 동작 (2026-11-27 변경)

1. 망고 폴더에서 A1이 `마켓주문일자`인 가장 최근 xlsx를 읽음
2. 망고변환 `중간`·`최종` 시트 수식과 같은 규칙으로 newPrice A~S 값 계산 (상품주문번호 추출, 문자 치환, 99바이트 자르기, 브랜드 18자, 공급가=단가+무게×3, 신고=단가×0.8)
3. 이미 Base에 있는 주문번호는 건너뜀
4. 품명의 한글 처리 (Base 품명에 한글 금지)
   - `크기:` `맛:` 같은 한글 옵션 이름표 삭제
   - 남은 한글 단어는 단어장 `ExcelAuto_단어장.xlsx`(exe 옆, 엑셀로 편집 가능)으로 바꿈
   - 단어장에 없는 단어는 DeepL로 번역해 단어장에 저장 (설정에 API 키가 있을 때만. 키는 Windows 자격 증명 관리자에 저장, 보내는 것은 한글 단어뿐)
   - 그래도 한글이 남으면 파일을 만들지 않음 → 미리보기 주황색 행을 두 번 눌러 직접 입력
5. `Base 폴더\추가분\Base_추가분_YYYYMMDD_HHMMSS.xlsx` 생성 후 열기 → 사용자가 Base newPrice에 값 붙여넣기 후 저장 (붙여 넣을 행 번호는 화면에 표시)

## ② 적하 작성 동작

1. 샵마인 다운로드 폴더에서 가장 최근 `발송대기*.xlsx`를 읽음
2. 품명은 Base newPrice + **오늘 추가분 파일**에서 찾음(붙여 넣기 전에도 진행 가능, 추가분이 우선)
3. 주문마다 `상품주문번호(AD)`, 없으면 `대표주문번호(AC)`로 `Base.xlsx` → `newPrice` F열(주문번호), 없으면 G열(바코드)을 찾아 I열 품명을 가져옴 (같은 번호가 여러 번이면 맨 아래 행)
4. 샵마인 F~V열 → Shipping C~S열, 품명 → AC, 수량(AI) → AF, 고정값(T~Z, AH, AM)과 수식(AB, AP, AQ) 입력
5. 첫 행 B열에 시작 송장번호(HAWB) 입력 (InvoiceAuto가 이 번호부터 부여)
6. `InvoiceAuto\ShippingInvoice` 폴더에 `Shipping_YYYYMMDD_HHMMSS.xlsx`로 저장
7. **품명을 못 찾은 주문이 하나라도 있으면 파일을 만들지 않고 목록을 보여줌** (InvoiceAuto는 품명 없는 행을 건너뛰므로 누락 방지)

## ③ 인보이스 실행 전 확인

- 최신 Shipping 파일의 품명이 Base.xlsx newPrice에 모두 있는지 검사 (InvoiceAuto는 품명이 정확히 같아야 찾음). 없으면 목록 표시

## 화면 (A안 단계 안내형, PySide6)

- 왼쪽에 오늘 할 일 5단계(망고 → Base, 적하 작성, 인보이스 실행, CR·송장 업로드 파일, 출고 체크), 완료 표시와 "지금 할 차례"
- 실행 전 미리보기 표: 새로 추가할 주문 / 이미 있는 주문, 품명 찾음 / 확인 필요
- 시작 송장번호: 지난 Shipping 파일의 시작 번호 + 건수로 다음 번호를 제안 (번호가 1씩 증가한다는 가정. 실행 전 확인). PTS 파일은 읽지 않음
- 진행 팝업: 0.4초 넘게 걸리는 작업은 단계(1/3…), 진행률(행 수를 알 때 실제 %), 경과 시간·지난번 걸린 시간, 취소(파일 쓰는 단계 제외)를 표시
- 실행 시작 때 "불러오는 중" 스플래시 (PyInstaller `--splash`), 창이 열리면 맨 앞으로, 이미 실행 중이면 새로 열지 않고 기존 창을 앞으로
- 작업 기록·완료 단계는 exe 옆 `ExcelAuto_state.json`에 저장

## 받기 / 실행

- GitHub → Actions → build-exe → 최근 실행 → Artifacts `ExcelAuto` 다운로드 → zip을 풀어 **`ExcelAuto` 폴더째** 원하는 곳에 두고 안의 `ExcelAuto.exe` 실행 (Python 설치 불필요)
- 폴더형 배포: 실행할 때마다 압축을 풀지 않아 시작이 빠름. exe만 따로 옮기면 실행되지 않음 (바로가기를 쓰기)
- 처음 실행 시 `설정`에서 경로 지정 (같은 폴더에 `ExcelAuto.ini` 생성)
- 스플래시 그림은 `python tools/make_splash.py`로 다시 만들 수 있음
