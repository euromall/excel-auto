# ExcelAuto

주문·적하 엑셀 반복작업 자동화. 인보이스 프로그램(InvoiceAuto, `invoice_2610`)과 **별도로** 만들어 테스트한 뒤 합칠 예정.

## 현재 기능 (v0.3)

| 기능 | 대체하는 작업 | 상태 |
|---|---|---|
| ① 망고 → Base (`ExcelAuto.exe`) | 2~3단계: 망고변환 파일(망고→중간→최종) 규칙 적용, Base.xlsx newPrice에 오늘 블록 추가 | 11-24 실제 7건·망고변환 90건과 결과 일치. 엑셀 자동 입력(COM)은 Windows 실행 검증 전 |
| ② 적하 작성 (`ExcelAuto.exe`) | 6~8단계: 샵마인 수령인 정보 → 적하, 품명 조회(주문재고변환 `변환` 시트), 품명·수량 입력, Shipping 파일 만들기 | 2026-11-24 실제 파일로 결과 일치 확인 |
| 출고 체크 매크로 (`vba/ShipScan.bas`) | 14단계: 송장 스캔 → 출고일 기록, 출고현황 시트 | 엑셀 실행 검증 전 |

## ① 망고 → Base 동작

1. 망고 폴더에서 A1이 `마켓주문일자`인 가장 최근 xlsx를 읽음
2. 망고변환 `중간`·`최종` 시트 수식과 같은 규칙으로 newPrice A~S 값 계산 (상품주문번호 추출, 문자 치환, 99바이트 자르기, 브랜드 18자, 공급가=단가+무게×3, 신고=단가×0.8)
3. 이미 Base에 있는 주문번호는 건너뜀 (두 번 실행해도 중복 없음)
4. Base\backup 에 백업 후, **엑셀을 통해** 마지막 블록 다음 템플릿 행에 날짜, 그 아래에 오늘 행을 값으로 입력
   - openpyxl로 저장하면 수식 셀의 계산값이 사라져 InvoiceAuto(data_only로 읽음)가 공급가를 못 읽기 때문
   - 엑셀/pywin32가 없으면 `Base_추가분_YYYYMMDD.xlsx`(붙여넣기용)만 만듦
5. 4단계(주문재고변환 `목록` 붙여넣기)는 ②가 Base를 직접 읽으므로 생략

## ② 적하 작성 동작

1. 샵마인 다운로드 폴더에서 가장 최근 `발송대기*.xlsx`를 읽음
2. 주문마다 `상품주문번호(AD)`, 없으면 `대표주문번호(AC)`로 `Base.xlsx` → `newPrice` F열(주문번호), 없으면 G열(바코드)을 찾아 I열 품명을 가져옴 (같은 번호가 여러 번이면 맨 아래 행)
3. 샵마인 F~V열 → Shipping C~S열, 품명 → AC, 수량(AI) → AF, 고정값(T~Z, AH, AM)과 수식(AB, AP, AQ) 입력
4. 첫 행 B열에 시작 송장번호(HAWB) 입력 (InvoiceAuto가 이 번호부터 부여)
5. `InvoiceAuto\ShippingInvoice` 폴더에 `Shipping_YYYYMMDD_HHMMSS.xlsx`로 저장
6. **품명을 못 찾은 주문이 하나라도 있으면 파일을 만들지 않고 목록을 보여줌** (InvoiceAuto는 품명 없는 행을 건너뛰므로 누락 방지)

## 화면 (v0.3, A안 단계 안내형, PySide6)

- 왼쪽에 오늘 할 일 5단계(망고 → Base, 적하 작성, 인보이스 실행, CR·송장 업로드 파일, 출고 체크), 완료 표시와 "지금 할 차례"
- 실행 전 미리보기 표: 새로 추가할 주문 / 이미 있는 주문, 품명 찾음 / 확인 필요
- 시작 송장번호: 지난 Shipping 파일의 시작 번호 + 건수로 다음 번호를 제안 (번호가 1씩 증가한다는 가정. 실행 전 확인)
- 실행 시작 때 "불러오는 중" 스플래시 (PyInstaller `--splash`), 창이 열리면 맨 앞으로, 이미 실행 중이면 새로 열지 않고 기존 창을 앞으로
- 작업 기록·완료 단계는 exe 옆 `ExcelAuto_state.json`에 저장

## 받기 / 실행

- GitHub → Actions → build-exe → 최근 실행 → Artifacts `ExcelAuto` 다운로드 → `ExcelAuto.exe`를 원하는 폴더에 두고 실행 (Python 설치 불필요)
- 처음 실행 시 `설정`에서 경로 지정 (같은 폴더에 `ExcelAuto.ini` 생성)
- 스플래시 그림은 `python tools/make_splash.py`로 다시 만들 수 있음
